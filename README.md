# butikbayu

Boutique fashion storefront — product catalogue, about, and contact pages.

## Features

- Home page with product highlights and carousels (Swiper)
- Products catalogue
- About & contact pages
- Responsive layout with Tailwind CSS

## Tech

- Next.js 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS
- Swiper, Heroicons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```
